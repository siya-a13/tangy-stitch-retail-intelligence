# Tangy Stitch Retail Intelligence System v4

This version focuses on chart readability and visual consistency.

## Run

```bash
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## What changed
- High-contrast Plotly typography and axis labels
- Removed rainbow/default chart colours
- Replaced the noisy inventory treemap with a readable ranked inventory chart
- Added visible value labels to major analytical bars
- Tightened the material → product flow to the strongest recorded relationships
- Kept the forecasting and decision labs with transparent demo-data labelling
